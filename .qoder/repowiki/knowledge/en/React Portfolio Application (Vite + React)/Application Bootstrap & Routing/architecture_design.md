Three entry points form a clear bootstrap chain: `src/main.tsx` creates the ReactDOM root, wraps the app in `StrictMode` and a `QueryClientProvider`, then mounts `<AppRouter />`. `src/router/index.tsx` declares the entire route tree via `createBrowserRouter`, exposing a single `AppRouter` component that renders through `RouterProvider`. Routes are split into two groups: public pages (`/`, `/login`) and a nested `/admin` subtree under `AdminLayout` protected by a local `ProtectedRoute` wrapper that reads auth state from `../store/authStore`. `src/App.tsx` is the legacy single-page layout used outside the router, composing top-level chrome (`Navbar`, `Footer`, `FloatingScrollButton`) with section components. Dependency direction is strictly inward: main → router → pages/layouts/store; App.tsx depends only on presentational components and is not used when the router is active.
