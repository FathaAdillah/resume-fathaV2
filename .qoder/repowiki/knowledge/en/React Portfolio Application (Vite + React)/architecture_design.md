The root configures the Vite build (vite.config.ts), TypeScript compilation (tsconfig.json, tsconfig.app.json, tsconfig.node.json), ESLint (eslint.config.js), and Docker deployment (Dockerfile, docker-compose.yml). Entry point index.html loads the React app whose bootstrap lives in the routing_and_app child, which wires TanStack Query and react-router-dom routes. The public_pages child renders the landing and login views composed from shared Navbar/Footer, while state_and_services provides the Zustand auth store, Axios client, and intersection observer hook consumed by both public and admin route handlers. Docker containers serve the built assets via Nginx.
