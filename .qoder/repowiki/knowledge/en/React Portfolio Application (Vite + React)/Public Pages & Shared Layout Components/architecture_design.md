Two top-level route components live under `src/pages/`: `LandingPage.tsx` composes a full-screen single-page layout by stacking `Navbar`, a `<main>` block of section components (`HeroSection`, `AboutSection`, `ExperienceSection`, `EducationSection`, `KnowledgeSection`, `SkillsSection`, `ProjectsSection`, `CertificationSection`), `Footer`, and a `FloatingScrollButton`. `LoginPage.tsx` is a standalone auth form that reads/writes the global auth state via `useAuthStore` and navigates to `/admin` on success. Shared chrome lives under `src/components/`: `Navbar.tsx` drives in-page anchor scrolling with active-section detection via a scroll listener, and `Footer.tsx` renders contact info, social links, and a client-side message form — both pull profile data from `../data/resume`. Dependency direction is one-way: pages import components; components import only local UI helpers (lucide icons) and shared data stores, never each other.
